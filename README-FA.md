# وب‌سایت شخصی بهنام جوج

این بسته برای انتشار روی GitHub Pages آماده شده است.

## ساختار فایل‌ها

- `index.html` — صفحه اصلی
- `projects.html` — صفحه فهرست پروژه‌ها
- `assets/css/style.css` — استایل صفحات
- `assets/js/main.js` — منوی موبایل و فیلتر پروژه‌ها
- `assets/favicon.svg` — آیکون سایت
- `projects/chess-online/index.html` — پروژه شطرنج قابل اجرا

## نصب در مخزن GitHub Pages

مخزن مورد نظر: `behnamjooj/behnamjooj.github.io`

1. از صفحه مخزن، وارد `Add file` و سپس `Upload files` شو.
2. محتویات داخل این پوشه را آپلود کن، نه خود پوشه‌ی `behnamjooj-portfolio` را به‌عنوان یک پوشه تو در تو.
3. فایل‌ها باید دقیقاً در این مسیرها قرار بگیرند:
   - `/index.html`
   - `/projects.html`
   - `/assets/css/style.css`
   - `/assets/js/main.js`
   - `/assets/favicon.svg`
   - `/projects/chess-online/index.html`
4. اگر GitHub پرسید، `Commit changes` را بزن.
5. پس از انتشار، صفحه اصلی باید در `https://behnamjooj.github.io/` و فهرست پروژه‌ها در `https://behnamjooj.github.io/projects.html` باز شود.
6. لینک شطرنج باید در `https://behnamjooj.github.io/projects/chess-online/` باشد.

## مهم درباره فایل‌های پروژه

- فایل شطرنج فعلی به‌صورت یک فایل HTML مستقل است و در این بسته داخل مسیر مناسب کپی شده.
- پروژه شطرنج برای حالت‌های معمولی به فایل‌های همین صفحه متکی است؛ حالت آنلاین از کتابخانه PeerJS و سرویس ارتباطی خارجی استفاده می‌کند و ممکن است بسته به اینترنت/دسترسی شبکه کار نکند.
- کارت‌های ابزار یادگیری زبان، تقویم فارسی، پژوهش هوش مصنوعی و موسیقی در صفحه پروژه‌ها معرفی اولیه‌اند. برای اینکه آن‌ها هم اجرا شوند، باید فایل‌های واقعی یا لینک مخزن/نسخه منتشرشده‌شان را جداگانه اضافه کنیم.
- فونت Vazirmatn از Google Fonts دریافت می‌شود؛ در صورت نبود اینترنت، فونت جایگزین استفاده می‌شود.

## افزودن پروژه جدید

برای هر پروژه وب، یک پوشه مستقل بساز؛ مثلاً:
`projects/name-of-project/index.html`

سپس در `projects.html` یک کارت به پروژه اضافه کن و لینک آن را به همان مسیر بده. اگر پروژه چند فایل دارد، کل ساختار و پوشه‌هایش را همان‌طور نگه دار. از آپلود فایل ZIP به‌تنهایی برای نمایش مستقیم در سایت استفاده نکن؛ ZIP را باز کن و فایل‌ها را در مسیر درست قرار بده.
